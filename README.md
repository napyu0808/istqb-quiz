# ISTQB FL 퀴즈

ISTQB CTFL(Foundation Level) v4.0 대비 인터랙티브 퀴즈.
**공식 샘플문제 A v1.7의 66문항만** 수록했습니다.

## 원칙

- **AI가 만든 문제는 하나도 없습니다.** 지문·선택지·정답·해설 전부 공식 PDF에서 그대로 옮겼습니다.
- **모든 문항에 실러버스 근거 절(§)을 표시**합니다. 틀리면 바로 원문으로 돌아갈 수 있습니다.
- 공식 해설은 정답뿐 아니라 **a·b·c·d 각 선택지가 왜 오답인지**를 전부 제공합니다. 그대로 실었습니다.

## 수록 현황

| 장 | 주제 | 문항 | 실전 모드 출제 |
|---|---|---|---|
| 1장 | 테스팅의 기초 | 14 | 8 |
| 2장 | SDLC와 테스팅 | 10 | 6 |
| 3장 | 정적 테스팅 | 8 | 4 |
| 4장 | 테스트 분석과 설계 | 15 | 11 |
| 5장 | 테스트 활동 관리 | 17 | 9 |
| 6장 | 테스트 도구 | 2 | 2 |
| **합계** | | **66** | **40** |

- 실러버스 **64개 LO를 모두 커버**합니다 (FL-4.2.2, FL-5.1.4는 2문항씩).
- K레벨 분포: K1 14 / K2 42 / K3 10
- 문항 형식: 단일정답, 복수정답(Q6·Q31·A7·A25), 4:4 매칭형(Q13·Q34), 조합형(i~v)

## 모드

- **장별 (1~6장)** — 선택 즉시 정답과 선택지별 해설 공개
- **실전 모의시험** — 40문항, 실제 비율(8/6/4/11/9/2), **60분 카운트다운**, 해설은 제출 후 일괄 공개, 합격선 65%(26/40)
- **공식 전체** — 66문항 전부

## 실행

브라우저에서 `index.html`을 열면 됩니다. 서버도 빌드도 필요 없습니다.
(데이터를 `<script src>`로 불러오므로 `file://`에서도 동작합니다.)

## 검증

66문항의 **정답·LO·K레벨을 공식 해설 PDF의 정답표와 전수 대조**해 불일치 0건을 확인했습니다.

## 구조

```
index.html        UI·로직 (React 18 CDN, 빌드 없음)
data/ch1.js~ch6.js  장별 문항 데이터
img/q23-state.png   Q23 상태 전이 다이어그램 (공식 PDF에서 추출)
```

문항을 고치거나 추가하려면 `data/chN.js`만 편집하면 됩니다.
